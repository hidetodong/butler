# Composer

![status](https://img.shields.io/badge/status-WIP-yellow)

> 🚧 **Work In Progress** — 本子系统当前仅有目录级入口说明，规则与内部结构尚未展开。

`Composer/` 是 butler 体系中的杂项事务入口。

它用于承载 `Coder/` 与 `Learner/` 之外的其他任务与后续扩展内容。

可覆盖的方向包括但不限于：

- 日常事务
- 临时协作事项
- 通用整理类工作
- 其他未归类任务

当前阶段仅保留目录级入口说明，后续规则与内部结构暂未展开。

当其他应用或文件需要引用该子系统时，应直接以 `Composer/README.md` 作为入口。
