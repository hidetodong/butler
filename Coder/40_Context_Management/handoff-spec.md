# 会话交接快照规范

本文件是 `SESSION_HANDOFF.md` 的唯一结构契约。其他规则若提到 handoff 且涉及文件字段，应以本文件为准。

每个 `SESSION_HANDOFF.md` 必须保持精简（控制在 500 Tokens 以内），且包含：

1. **任务断点：** 当前正在进行的 AC 条目。
2. **共识快照：** 已经确定的接口契约或数据结构（避免重复讨论）。
3. **环境脏点：** 当前未提交的代码、临时关闭的 Lint 规则。
4. **唤醒指令：** 下一个 Session 启动时，AI 应该执行的第一条命令。
