> 区间: v2.16.0 → v2.17.0 · 聚合 ITER-0056–ITER-0060（MILE-0007）· **MINOR**

## 对已部署项目的影响

本版不迁移 `.ai/` 结构。目标项目的规则卡要重生成，以带入“自动测试/复核必须引用机器证据”等收口约束；机器级安装要刷新 Claude 全局入口与 Butler Codex plugin。项目升级随后把 CLAUDE.md/AGENTS.md 版本戳对齐 v2.17.0。

## 迁移步骤

1. `[global-install]` 在 Butler 仓运行 `bash scripts/setup.sh`，刷新安全安装 helper、Claude 全局命令与个人 Codex plugin。HOME 修改必须单独显式确认；冲突或 validator 失败即停。
2. `[regen-entrypoints]` 运行 `python3 "$BUTLER_PATH/scripts/render-project-entrypoints.py" --target "$PROJECT_ROOT" --butler-root "$BUTLER_PATH"`，从单一 rule-card 重生成 CLAUDE.md/AGENTS.md 管理区；用户区与管理区外原文保留，marker 异常即停。
3. `[restamp]` 由同一 renderer 把两入口版本戳对齐 v2.17.0；内容漂移或两戳不一致不得只靠版本号掩盖。

## 不需要动作

- `.ai/` 四件套、迭代/里程碑台账与知识文件夹路径不变。
- 不向目标项目复制升级器、证据工具、CI 或 workflow registry；这些工具驻留 Butler 仓，由 `$BUTLER_PATH` 调用。
- 不自动配置 GitHub required checks、team/public marketplace 或 hook trust；这些仍是外部显式动作。
