> 区间: v3.3.0 → v3.4.0 · 聚合 ITER-0096–ITER-0101 · **MINOR**

## 对已部署项目的影响

本版新增 Butler 语义 Router、会话转迭代入口和旁路工作回执，并修复机器级 plugin 刷新与 setup 错误回声。既有项目的 `.ai/` 结构、双入口 managed block 和 hook 部署树没有新增必须复制的项目文件，因此项目侧只需更新版本戳。

## 迁移步骤

1. `[global-install]` 在 Butler 仓运行 `bash scripts/setup.sh`，刷新 Claude 根命令与命名空间命令、Codex plugin/skills 和 Pi 扩展；这是机器级动作，必须单独确认。
2. `[restamp]` 把目标项目双入口版本戳对齐 v3.4.0。

## 兼容与回写边界

- Router 只选择一个主工作流；显式具体入口继续直达，`loop` 与 `dangerous` 仍禁止隐式开启。
- 会话转迭代只持久化结晶后的决定、建议和开放问题，不保存原始会话全文；已有 active 时拒绝再分配新号。
- plugin validator 仍不可跳过：无 uv 时只复用能导入 PyYAML 的既有 Python runtime，全部不可用则明确失败。
- 当前 Codex 会话不会热加载刷新后的 plugin，需新开会话生效。
