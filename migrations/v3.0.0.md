> 区间: v2.18.0 → v3.0.0 · 聚合 ITER-0075–ITER-0082 · **MAJOR**

## 对已部署项目的影响

本版把单份 PRD 契约升级为按 `prd_id` 隔离的多 PRD 集合，并新增工作区范围 hook。旧项目必须先按 `docs/prd-migration-guide.md` 审阅并显式执行 PRD 迁移；升级器不会自动改写用户需求内容。

## 迁移步骤

1. `[global-install]` 在 Butler 仓运行 `bash scripts/setup.sh`，刷新 Claude 全局命令、Codex plugin 与 Pi 扩展；执行前需明确确认机器级安装，Codex/Pi 不可用时按安装器既有规则降级。
2. `[sync-hooks]` 对比目标项目 `.claude/hooks/` 与本版真源；只有 hook 树可识别或尚不存在且 settings 结构合法时才同步，检测到用户漂移立即停止并报告差异。
3. `[restamp]` 由统一 renderer 校验 CLAUDE.md/AGENTS.md marker 后，把两入口版本戳对齐 v3.0.0；marker 异常时停止，不覆盖 user-managed 内容。

## 不需要动作

- 升级器不自动搬迁旧 `prd/` 内容；按 `docs/prd-migration-guide.md` 使用 `tools/prd-migrate/prd_migrate.py` 先 plan、人工确认后再 apply。
- 已经采用新版日期化多 PRD 结构的项目无需重复迁移；迁移工具会以结构和 hash 校验保持幂等、漂移即停。
