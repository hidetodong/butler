## 对已部署项目的影响

- **对目标项目 `.ai/` 部署面无结构迁移（`[no-op]`）**：ITER-0046 改的是 butler 仓的**全局安装脚本**（`scripts/setup.sh` 加 `@import` 行）+ 新增仓根一份**个人配置文件** `communication-style.md` + 文档。这些都不在逐项目部署产物里——目标项目的 `.ai/` / `deliveries/` / `origin/` / `CLAUDE.md` / `.claude/hooks/` 均无任何结构变化。
- **沟通风格走全局 @import、非逐项目模板**：正本**不进** `templates/`（`git diff v2.5.0..v2.6.0 -- templates/` 为空），不随基地车部署逐项目落地。它 `@import` 进的是**机器级**的全局 `~/.claude/CLAUDE.md`，与目标项目 `CLAUDE.md` 无关。因此内联规则卡、hook 体系、`settings.hooks-snippet.json` 均无更新 → 无需 `[regen-claude]` / `[sync-hooks]`。
- **无破坏性变更**：无规则文件重命名 / 删除、无 schema 必填字段增删、无产物链阶段重排、无 hook 拦截契约变更、无命令语义不兼容变更 → 无 MAJOR 级迁移动作。

## 迁移步骤

> 本版对目标项目 `.ai/` 部署面**无结构迁移**（`[no-op]`）；但要在本机拿到「AI 按沟通风格正本说话」，需一个**机器级**动作（不是逐项目动作）。

1. `[global-install]` **重跑一次 `./scripts/setup.sh`**（在 butler 仓目录下）——它会在全局 `~/.claude/CLAUDE.md` 的 butler 受管配置块内写入一行 `@<BUTLER_DIR>/communication-style.md`，AI 随即在**所有项目**按该正本的语气 / 详略 / 说人话规矩说话。幂等、可反复跑；正本随 butler 仓走，之后改说话风格只改 `communication-style.md` 即全局生效、无需再装。这是一次性机器级动作，与逐项目升级无关。（历史曾写作散文标签 `[global-install-rerun]`，现按 schema 归一为 `[global-install]`，动作意图不变。）
2. `[restamp]` 版本戳 → v2.6.0（按 `mcv-deployment.md §3` 重戳目标 `CLAUDE.md` butler 管理区的 `{{BUTLER_VERSION}}`；`<!-- user-managed -->` 保护区原样保留）。

> 仅当这台机器上还留着 ITER-0046 之前的过渡产物时才需要；不影响任何目标项目，纯粹是清掉已被正本取代的旧物。

- 删 `~/.claude/output-styles/matrix.md`（Matrix 输出风格已退休，规矩全部并入正本）。
