> 区间: v3.5.1 → v3.6.0 · 聚合 ITER-0107 ~ ITER-0111 · **MINOR**

## 对已部署项目的影响

本版新增领域模型治理：五个限界上下文与统一语言、L0 到 L3 的分层按需加载、主链五段转换合同，以及最小领域合同和上下文预算两个驻留工具。落到部署项目的只有两处——

1. **`CLAUDE.md` / `AGENTS.md` 的内联规则卡**：新增一小段「核心概念渐进读取（L0）」读取纪律（约 234 token）。它由 `templates/rule-card.md` 注入，不重新生成入口就一直是旧的。同期规则卡另有删减，实测重新生成后的入口体量比 v3.5.1 略低约 4%。
2. **活跃迭代的 live `.ai/VERIFY_REPORT.md`**：canonical v1 的 strict 结构新增固定段「人测道小结」（本轮无人测就填 N/A）。只有在升级前已经渲染过 VERIFY 的活跃迭代才受影响，需要显式补段（见下方「显式项目迁移」）；没有活跃迭代时，下次 P5 直接按新模板渲染，无需动作。

领域地图、术语表、主链合同和领域合同注册表都留在 Butler 仓，由运行时按 `$BUTLER_PATH` 实时读取，不拷进目标项目。hook 树与 `.ai/` 其余结构没有变化。

## 迁移步骤

1. `[global-install]` 在 Butler 仓运行 `bash scripts/setup.sh`，刷新 Claude 全局命令与 Codex plugin（plugin 版本随本版升到 3.6.0）。执行前需明确确认机器级安装；Codex CLI 不可用时明确跳过。
2. `[regen-entrypoints]` 用统一 renderer 重新生成 `CLAUDE.md` 与 `AGENTS.md` 的 Butler 管理区，把新增的 L0 读取纪律注入两个入口。起始态校验：两份文件的 managed block marker 完整且不重复，marker 外的 user-managed 内容逐字保留；marker 残缺或重复即停，不覆盖。
3. `[restamp]` 在双入口 marker 校验通过后，把目标项目版本戳对齐 v3.6.0，两份必须一致。

## 显式项目迁移

- **live 五件套的 VERIFY 补段**：只在有活跃迭代、且其 `.ai/VERIFY_REPORT.md` 已渲染时才需要。先运行 `python3 "$BUTLER_PATH/tools/artifact-pipeline/migration.py" plan --project-root "$PROJECT_ROOT"` 审阅差异，确认后 `apply`，再按 receipt 的 migration ID 执行 `verify`；需要回退时执行 hash-gated `rollback`。工具只在该段缺失时插入，位置以「Evidence Index」标题为锚点，重复执行不重复改；段落重复或章节顺序异常时拒绝改写并打印实际标题序列，交用户手工归位。
- 历史 `.ai/iterations/` 归档保持只读，不追溯补段、不重排章节。

## 不需要动作

- 不需要把 `Coder/domain-model.md`、`Coder/domain-glossary.md`、`Coder/context-map.md`、`tools/domain-contract/domains.v1.json` 拷进目标项目——这些由运行时按 `$BUTLER_PATH` 实时读取，改了立即生效（判据见 `migration-schema.md §5`）。
- 不需要为既有项目预先建立领域地图、术语记录或领域合同条目；这套注册表是 Butler 自身的治理面，不在目标项目落盘。
- 不需要同步 hook 树：本版 `templates/hooks/` 与 settings 片段零改动。
- 不需要为 Dangerous Mode 与 Convergence Loop 解绑做任何项目侧动作。两者本来就是并列模式，本版只修正了规则正文里的错误包含措辞，没有改命令、路径或状态值。
- 不需要改动 `.ai/butler.config.json` 或任何既有状态台账字段。

## 兼容与回写边界

- L0 只是读取纪律，不是机械 loader。它约束 Agent 按层读取领域知识，不改变任何阶段流程、产物结构或验收标准。
- 领域合同的条目覆盖门只在 Butler 仓的完整 CI 里跑，不下发到目标项目、不拦目标项目的提交。
- 「人测道小结」缺省值是 N/A。补段不代表本轮有人测任务，也不会凭空生成人测结论。
- 当前 Codex 会话不会热加载刷新后的 plugin，需新开会话生效。
