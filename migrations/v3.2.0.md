> 区间: v3.1.0 → v3.2.0 · 聚合 ITER-0090–ITER-0092 · **MINOR**

## 对已部署项目的影响

本版新增机器级 setup 入口和 opt-in TDD Red→Green 收口能力。不会自动改写目标项目的 `.ai/` 历史或当前产物；只有新 TECH_PLAN 显式声明 TDD cycle 时，P5/Goal 才增加配对义务。

## 迁移步骤

1. `[global-install]` 在 Butler 仓运行 `bash scripts/setup.sh`，刷新 Claude 全局入口、Codex plugin 与 Pi 扩展；执行前需明确确认机器级安装。
2. `[regen-entrypoints]` 运行 `python3 "$BUTLER_PATH/scripts/render-project-entrypoints.py" --target "$PROJECT_ROOT" --butler-root "$BUTLER_PATH"`，从单一 rule-card 重生成 CLAUDE.md / AGENTS.md 管理区，使 Goal 收口规则包含 opt-in TDD 配对检查。
3. `[restamp]` 由同一 renderer 把两入口版本戳对齐 v3.2.0。

## 不需要动作

- 不自动迁移历史 VERIFY 归档，legacy 产物继续只读兼容。
- 不向目标项目复制 Goal、verification evidence 或 artifact pipeline 工具；它们仍从 Butler 仓驻留调用。
- 未声明 TDD cycle 的迭代保持 N/A，不新增收口门。
