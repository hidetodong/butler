本次交付目标

  • butler 的命令长期停在「一个真命令 + 一堆散文触发词」：ITER-0044 落了第一个真命令 /butler-prd（连字符扁平命名），ITER-0045 打通全局软链让它所有项目可用。但整套 butler 能力（/milestone、/review、/loop、/dangerous 等）仍只是规则正文里的暗号，补全菜单里看不见；扁平通用名全局装还易和别的插件撞名。
  • 本次搭起 /butler:xxx 命名空间体系的地基（MILE-0005 第一步）：新建 .claude/commands/butler/ 命名空间目录（Claude Code 里子目录＝冒号前缀，butler/<name>.md→/butler:<name>），把 /butler-prd 破坏性迁成 /butler:prd，改 setup.sh 让整个命名空间目录随一条软链全局可用，并落第一个新命令 /butler:review 证明「薄壳路由器」范式在命名空间下可复制——为后续 R2–R4 批量加命令铺好骨架与迁移范本。

已完成内容

  • 新建命名空间目录 .claude/commands/butler/：子目录名即冒号前缀。butler: 前缀天然隔离撞名——全局安装通用名（/review、/loop）不再和别的插件/用户自定义命令冲突。
  • /butler-prd 破坏性迁成 /butler:prd：git mv .claude/commands/butler-prd.md → butler/prd.md，正文 byte-identical 零改（三分支路由 留空/贴 PRD=首切·update=改版·status=只读看板 一字未动；原文本就从不自称命令名）。旧全局软链 ~/.claude/commands/butler-prd.md 由 setup.sh 迁移清理段兜底删除。
  • 新落 /butler:review（纯薄壳路由器范本）：命名空间第二个成员，也是后续命令的复制样板。只做三件事——把对的规则读进上下文、按 $ARGUMENTS 分派、委托真源不复述算法（守 DRY）：默认（留空）→ 当前上下文快速自检（review-engine §5）；independent → 另起干净子 agent 独立复核（independent-review + overview §3，验证者≠作者）。第 0 步先判「当前项目有没有接 butler」，没接就优雅提示而非报错。
  • setup.sh 软链改造：从「逐个软链 .claude/commands/*.md」改为 ln -sfn 软链整个 butler/ 命名空间目录 → ~/.claude/commands/butler——一条目录软链托管全套，butler 仓里加/改命令即全局生效、无需重跑。含迁移清理段（-L 判定只删旧扁平软链、绝不误删用户自放的真文件）+ -n 防 butler/butler 套娃 + 命令计数提示。
  • 4 处活文档引用更新：README.md（目录树重构出 butler/ 子树含 prd+review）、HUMAN_GUIDE.md（软链描述改命名空间目录）、.ai/project/capabilities.md（命令名+路径+setup 机制句）、.ai/project/frontier.md（3 处）。历史「原名 /butler-prd」陈述与 setup.sh 迁移清理代码合法保留旧名；冻结归档一律不动。
  • 迁移配方 + 切版：migrations/v2.7.0.md（个人命令层 [rename] + 部署面 [no-op]+[restamp] + [global-install] 机器动作）；VERSION 2.6.1→2.7.0、CHANGELOG 顶条 [2.7.0]（判 MINOR）。

关键变更 / 用户可感知变化

  • 命令改名：/butler-prd 停用、改敲 /butler:prd（路由行为一字未改）。重跑一次 ./scripts/setup.sh 即完成切换（自动清旧软链 + 装命名空间目录软链）；跳过重跑仍敲旧名会找不到命令——重跑即好。
  • 多了个 /butler:review：给当前迭代的改动做复核——默认当前上下文快速自检，或 /butler:review independent 另起干净上下文做更狠的独立复核（验证者≠作者）。
  • 以后加命令更省事：setup.sh 现在软链整个 butler/ 目录，往里丢一个新 .md 就自动在所有项目全局可用，无需再动分发、无需重跑 setup。
