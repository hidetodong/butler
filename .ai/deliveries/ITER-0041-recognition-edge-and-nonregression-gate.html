关键变更 / 用户可感知变化

  • 改版认亲不再断身份：模块改个名，不再被当成"旧的没了 + 新的冒出来"两条无关记录——只要你确认，slug 终身链续得上，跨版本审计对得齐。合并/拆分同理有章可循。
  • 但绝不自动认：认亲全是"机器提候选、你拍板"。机器拿不准就老实退回基础态，绝不擅自把两个模块并成一个（那会让规格串味）。
  • "不碰老路"从承诺变成可验证的门：以后任何一次改 PRD 子系统，非 PRD 老路的 git diff 为空是硬性收口条件——不用再靠人肉记得"别碰对话流"。
  • 人类用户第一次有了 /prd 说明书：HUMAN_GUIDE 里能读到 PRD 先行是什么、改版怎么走、为什么绝不暗中改你验收过的活。
  • 不用 PRD 的人依旧完全无感：本轮恰恰是亲自守住那条门——改动全在 PRD 子系统 + HUMAN_GUIDE 用法节，普通开发流一字未动。
