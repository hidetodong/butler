本次交付目标

机器上只有 Grok 时，别的项目也能用 Butler。写文件仍走现有门禁。找不到 Grok 时，原来三家宿主的安装保持原样。

已完成内容

  • 安装脚本发现 Grok 时，把技能目录软链到 ~/.grok/skills/。找不到就跳过，不创建这个目录。同名位置如果已是真实文件或目录，就停下，不删除。
  • 门禁把 Grok 的 write 和 search_replace 译成现有的 Write 和 Edit。终端命令不进入这套判断。
  • README、使用指南和兼容说明写明 Grok 是宿主，并写明软链安装、找不到就跳过、两份入口都会被读到。
  • 本机另开的会话能从用户技能目录调用 butler-inbox。该拒绝的写入没有改掉文件。

关键变更 / 用户可感知变化

  • 重跑安装脚本之后，新的 Grok 会话可以在别的项目里看到 Butler 技能。
  • 项目如果部署了现有钩子，并且目录已被信任，Grok 的写文件会碰到同一套拒绝。
  • 没有 Grok 的机器，安装结果和以前一样。
  • 版本号仍是 4.0.0。发布标签没有移动。
