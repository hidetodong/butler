项目外写入授权边界

ITER-0067 迭代交付（小版本） 收口 2026-07-18

本次交付目标

  • 让 Butler 只拦能归属项目的流程违规，不再抢在宿主权限之前拒绝真实项目外写入。
  • 让危险模式能在预授权范围内无人值守跨项目施工，同时不能自行扩大权限。

已完成内容

  • 坏输入继续拒绝，真实项目外目标交宿主决定。
  • Claude 与 Codex 按目标文件的真实 Butler / Git 根执行门禁。
  • Codex patch 支持多个项目根逐一校验，任一拒绝则整次拒绝。
  • 危险模式新增冻结授权上限和范围外依赖路由。

关键变更 / 用户可感知变化

  • 项目外配置不再要求 Butler bypass，宿主仍按自身权限决定。
  • 聚合目录和项目子目录场景会使用目标项目自己的流程状态。
  • 危险模式可在授权上限内动态发现兄弟项目，超出上限则隔离或诚实交还。

高层影响范围

  • 共享 hook 路径分类、项目根解析与 Codex 多目标分派。
  • 危险模式协议、部署说明、Coder 入口、规则卡和 hook 文档。
  • Codex wrapper E2E、147 项 hook 回归和完整双宿主 CI。

验证方式与结果摘要

  • final-hook-tests：147 项通过。
  • final-codex-wrapper：真实 plugin wrapper 路径通过。
  • final-full-ci：固定工具链和完整双宿主矩阵通过。
  • Goal adjudicator 十项检查全部通过，裁决 eligible。

已知剩余风险 / 延后事项

  • 本轮无未关闭实现风险。
  • 实际可写范围仍由宿主配置决定；本轮不发布、不推送、不升级外部项目。
